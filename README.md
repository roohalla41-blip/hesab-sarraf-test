# ATLAS AI | اطلس AI

اپلیکیشن دستیار هوش مصنوعی چندزبانه با تجربه فارسی‌محور، برای عرضه جهانی در Android و سپس پلتفرم‌های دیگر.

## هویت محصول
- برند: **ATLAS AI**
- نام فارسی: **اطلس AI**
- شعار: **هوشمندی بدون مرز**
- زبان شروع: فارسی راست‌به‌چپ؛ معماری آماده گسترش به دری و انگلیسی

## ساختار محصول
- گفت‌وگوی هوشمند و مدیریت گفتگوها
- تاریخچه، جست‌وجو، سنجاق و آرشیو
- بخش Explore برای دستیارها و کاربردهای تخصصی
- ابزارهای تصویر، فایل، وب و برنامه‌نویسی
- ورودی و خروجی صوتی
- حساب کاربری، سهمیه مصرف و اشتراک
- تنظیمات زبان، ظاهر، حریم خصوصی و دسترس‌پذیری

## معماری فنی
- Android: Kotlin + Jetpack Compose
- لایه‌های مستقل UI، Domain، Data و Core
- قرارداد مستقل برای درگاه هوش مصنوعی و تاریخچه محلی
- آماده توسعه به معماری چندسکویی در مراحل بعد

## امنیت
- کلید مدل هوش مصنوعی فقط در Secret Manager سرور نگهداری می‌شود.
- هیچ کلید محرمانه‌ای داخل اپ، APK یا GitHub قرار نمی‌گیرد.
- سرور مسئول انتخاب مدل، سهمیه، کنترل سوءاستفاده و ثبت مصرف خواهد بود.
- اتصال دیتابیس ابری و حساب کاربری تا تأیید جداگانه انجام نمی‌شود.

## وضعیت فعلی
این مخزن در مرحله تکمیل ساختار و پایه محصول است. درگاه هوش مصنوعی و مخزن تاریخچه فعلاً قراردادهای معماری هستند و به سرویس واقعی متصل نشده‌اند. پاسخ ساختگی به‌عنوان پاسخ مدل نمایش داده نمی‌شود. قابلیت‌های صوت، تصویر، فایل، وب، اشتراک و ورود تا زمان پیاده‌سازی و آزمایش، فعال محسوب نمی‌شوند.

## سیاست ساخت
ساخت APK و اجرای Build خودکار غیرفعال است. هیچ Build یا انتشار APK انجام نمی‌شود مگر با درخواست صریح کاربر.

جزئیات معماری در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) و نقشه محصول در [docs/PRODUCT_STRUCTURE.md](docs/PRODUCT_STRUCTURE.md) قرار دارد.

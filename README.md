# ATLAS AI | اطلس AI

اپلیکیشن دستیار هوش مصنوعی چندزبانه با تجربه فارسی‌محور، برای عرضه جهانی در Android و سپس پلتفرم‌های دیگر.

## هویت محصول
- برند: **ATLAS AI**
- نام فارسی: **اطلس AI**
- شعار: **هوشمندی بدون مرز**
- زبان شروع: فارسی راست‌به‌چپ؛ معماری آماده گسترش به دری و انگلیسی

## ساختار محصول
- گفت‌وگوی هوشمند و مدیریت گفتگوها
- تاریخچه محلی گفت‌وگوها
- بخش Explore برای دستیارها و کاربردهای تخصصی
- ابزارهای تصویر، فایل، وب و برنامه‌نویسی (فعلاً غیرفعال)
- ورودی و خروجی صوتی (فعلاً غیرفعال)
- حساب کاربری، سهمیه مصرف و اشتراک (هنوز پیاده‌سازی نشده)
- تنظیمات زبان، ظاهر، حریم خصوصی و دسترس‌پذیری
- راهنما و پشتیبانی

## وضعیت فعلی
- پیش‌نمایش وب و ناوبری اولیه Android برای بخش‌های اصلی ایجاد شده‌اند.
- Android اکنون می‌تواند گفت‌وگوها را در حافظه خصوصی خود دستگاه ذخیره و بازیابی کند.
- تاریخچه محلی محدود است؛ رمزنگاری اختصاصی و کنترل حذف/خروجی هنوز اضافه نشده‌اند.
- هیچ مدل هوش مصنوعی در برنامه متصل نیست و پاسخ هوشمند تولید نمی‌شود.
- حساب کاربری، ابزارها، اشتراک و همگام‌سازی ابری هنوز عملیاتی نیستند.
- بررسی کامپایل و آزمایش دستگاهی هنوز انجام نشده است.

## معماری فنی
- Android: Kotlin + Jetpack Compose
- لایه‌های مستقل UI، Domain، Data و Core
- درگاه هوش مصنوعی مستقل و غیرفعال تا آماده‌شدن سرویس اختصاصی ATLAS
- تاریخچه محلی JSON در حافظه خصوصی Android

## امنیت
- کلید مدل هوش مصنوعی فقط در Secret Manager سرور نگهداری می‌شود.
- هیچ کلید محرمانه‌ای داخل اپ، APK یا GitHub قرار نمی‌گیرد.
- سرور مسئول انتخاب مدل، سهمیه، کنترل سوءاستفاده و ثبت مصرف خواهد بود.
- اتصال دیتابیس ابری و حساب کاربری تا تأیید جداگانه انجام نمی‌شود.

## سیاست ساخت
ساخت APK و اجرای Build خودکار غیرفعال است. هیچ Build یا انتشار APK انجام نمی‌شود مگر با درخواست صریح کاربر.

جزئیات معماری در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)، سیاست حریم خصوصی در [docs/PRIVACY_AND_SAFETY.md](docs/PRIVACY_AND_SAFETY.md) و نقشه محصول در [docs/PRODUCT_STRUCTURE.md](docs/PRODUCT_STRUCTURE.md) قرار دارد. پیش‌نمایش وب در پوشه [preview](preview/) قرار دارد.

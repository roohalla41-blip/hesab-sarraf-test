# هوش مصنوعی

اپلیکیشن دستیار هوشمند اندروید؛ پروژه با Kotlin و Jetpack Compose آغاز شده و بک‌اند امن آن با Supabase Edge Functions طراحی می‌شود.

## اجزای پروژه

- `app/`: اپلیکیشن اندروید با رابط فارسی.
- `supabase/functions/chat/`: واسط امن بین اپلیکیشن و سرویس هوش مصنوعی.
- `supabase/config.toml`: تنظیمات محلی Supabase و الزام بررسی JWT برای تابع چت.

## وضعیت فعلی

- رابط اولیه چت فارسی اندروید: آماده به‌عنوان اسکلت، هنوز متصل به سرویس واقعی نیست.
- تابع سرور `chat`: کد اولیه اضافه شده؛ هنوز در هیچ پروژه Supabase مستقلی Deploy نشده است.
- احراز هویت کاربران، محدودیت مصرف هر کاربر، تاریخچه ابری، حالت آفلاین، گفتار و انتشار فروشگاهی: در مراحل بعدی.
- هنوز APK قابل انتشار ساخته و آزمایش نشده است.

## امنیت کلید هوش مصنوعی

کلید ارائه‌دهنده مدل باید فقط در بخش **Edge Function Secrets** پروژه مستقل Supabase ثبت شود؛ نام متغیر آن `AI_API_KEY` است.

متغیرهای لازم:
- `AI_API_KEY`: کلید خصوصی ارائه‌دهنده هوش مصنوعی.
- `AI_API_URL`: نشانی پایه API سازگار با قالب OpenAI؛ در صورت عدم تنظیم، مقدار پیش‌فرض `https://api.openai.com/v1` است.
- `AI_MODEL`: شناسه دقیق مدل مورد استفاده.

**کلید واقعی را در GitHub، فایل‌های برنامه اندروید، APK یا گفت‌وگو قرار ندهید.** پس از آماده شدن پروژه Supabase، کلید را مستقیماً در داشبورد Secrets وارد می‌کنیم؛ نیازی نیست آن را برای من ارسال کنید.

تابع فعلی با `verify_jwt = true` تنظیم شده است؛ بنابراین تا زمانی که احراز هویت کاربران و ارسال JWT از اپلیکیشن پیاده نشود، درخواست چت عمومی و قابل استفاده نخواهد بود. این رفتار عمداً برای جلوگیری از ساخت یک درگاه عمومیِ قابل سوءاستفاده انتخاب شده است.

## پیش‌نیازهای توسعه

- Android Studio و JDK 17
- Android SDK 35
- Supabase CLI برای اجرای محلی و Deploy تابع

## مراحل بعدی

1. ساخت یک پروژه Supabase مستقل برای این اپلیکیشن (نه پروژه حساب صراف).
2. تعیین ارائه‌دهنده، آدرس API و مدل؛ سپس ثبت Secrets در داشبورد Supabase.
3. پیاده‌سازی ثبت‌نام/ورود امن و محدودیت مصرف کاربران.
4. اتصال اپلیکیشن اندروید به تابع `chat` با نشست کاربر.
5. تست امنیت، خطاها، مصرف و عملکرد روی گوشی واقعی.
6. ساخت نسخه امضاشده و آماده‌سازی انتشار در فروشگاه‌ها.

# هوش مصنوعی

اپلیکیشن دستیار هوشمند اندروید؛ اسکلت اولیه با Kotlin و Jetpack Compose.

## وضعیت فعلی
- رابط کاربری چت فارسی
- پشتیبانی پایه از حالت روشن/تاریک سیستم
- صفحه تنظیمات برای واردکردن آدرس سرویس و کلید API در دستگاه
- کلیدها داخل مخزن یا کد منبع قرار نمی‌گیرند
- اتصال واقعی به مدل، اجرای آفلاین و گفتار در مراحل بعدی اضافه می‌شوند

## پیش‌نیازها
- Android Studio جدید
- JDK 17
- Android SDK 35

## اجرا
پروژه را در Android Studio باز کنید و ماژول `app` را اجرا کنید.

## امنیت کلید API
برای نسخه آزمایشی می‌توان کلید را فقط روی دستگاه وارد کرد. برای انتشار عمومی، کلید API را داخل APK قرار ندهید؛ درخواست‌ها باید از یک backend امن عبور کنند. این مخزن عمداً هیچ کلید یا رمز واقعی ندارد.

## مسیر توسعه
1. اتصال backend امن به ارائه‌دهنده مدل
2. ذخیره امن تنظیمات و تاریخچه گفتگو
3. موتور مدل محلی آفلاین
4. تبدیل گفتار به متن و متن به گفتار
5. تست روی گوشی‌های ضعیف و قوی

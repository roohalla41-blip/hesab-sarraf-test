# ATLAS AI | اطلس AI

اپلیکیشن دستیار هوش مصنوعی برای کاربران فارسی‌زبان افغانستان و ایران؛ ساخته‌شده با Kotlin و Jetpack Compose.

## هویت محصول

- نام برند: **ATLAS AI**
- نام فارسی: **اطلس AI**
- عنوان پیشنهادی فروشگاه: **هوش مصنوعی اطلس – دستیار هوشمند فارسی**
- شعار پیشنهادی: **هوشمندی بدون مرز**
- زبان رابط نسخه فعلی: فارسی و راست‌به‌چپ

## ساختار فعلی برنامه

- صفحه گفت‌وگوی اصلی
- نمایش پیام‌های کاربر و دستیار
- کادر نوشتن و ارسال پیام
- پیشنهادهای شروع سریع برای ترجمه، برنامه‌نویسی و یادگیری
- پنجره تنظیمات اولیه
- رنگ‌بندی پایه برند اطلس
- نام برنامه و هویت برند در رابط و لانچر اندروید

## وضعیت فعلی و محدودیت‌ها

این نسخه هنوز اسکلت اولیه است:
- اتصال واقعی به مدل هوش مصنوعی فعال نیست.
- پاسخ نمایشی فقط اعلام می‌کند که سرویس هنوز متصل نشده است؛ پاسخ ساختگی از مدل ارائه نمی‌شود.
- پیام‌ها فقط در حافظه موقت صفحه هستند و با بستن برنامه از بین می‌روند.
- ورود کاربر، تاریخچه دائمی، گفتار، بارگذاری تصویر و فایل هنوز پیاده‌سازی نشده‌اند.
- APK هنوز ساخته و روی دستگاه آزمایش نشده است.

## معماری و امنیت

- Android: Kotlin + Jetpack Compose
- Backend در مرحله بعد: Supabase Edge Function مستقل برای ATLAS AI
- کلید ارائه‌دهنده هوش مصنوعی: فقط در Secrets سمت سرور
- هیچ کلید محرمانه‌ای نباید در GitHub، کد اندروید، APK یا گفت‌وگو قرار گیرد.
- پروژه‌های Supabase حساب صراف و مخزن‌های B1/B2 خارج از محدوده این برنامه هستند.

## مراحل توسعه

1. تکمیل اسکلت رابط و هویت بصری
2. جداسازی لایه‌های رابط، منطق گفت‌وگو و تنظیمات
3. ساخت و آزمایش APK اولیه
4. انتخاب ارائه‌دهنده و مدل هوش مصنوعی
5. آماده‌سازی و اتصال فقط به Supabase مستقل ATLAS AI
6. پیاده‌سازی احراز هویت، محدودیت مصرف و مدیریت خطا
7. افزودن تاریخچه، گفتار و امکانات چندرسانه‌ای
8. آزمایش امنیت، عملکرد و انتشار فروشگاهی

## پیش‌نیازهای توسعه

- Android Studio
- JDK 17
- Android SDK 35

# ATLAS AI | اطلس AI

اپلیکیشن دستیار هوشمند چندسرویس با هدف انتشار عمومی در Google Play.

## هویت محصول
- برند: **ATLAS AI**
- نام فارسی: **اطلس AI**
- شعار: **هوشمندی بدون مرز**
- زبان رابط: تشخیص خودکار زبان دستگاه؛ فارسی برای دستگاه فارسی و انگلیسی برای سایر زبان‌ها در نسخه فعلی
- پلتفرم نخست: Android

## بخش‌های محصول
- گفت‌وگو و تاریخچه چندمکالمه‌ای محلی
- کاوش دستیارهای تخصصی
- ابزارها و مرکز اتصال ATLAS CONNECT
- پروفایل مهمان، تنظیمات و حریم خصوصی
- طرح‌های اشتراک؛ پرداخت تا زمان اتصال درگاه غیرفعال است
- راهنما و پشتیبانی

## وضعیت واقعی پیاده‌سازی
- رابط Android با Kotlin و Jetpack Compose ساخته شده و صفحات اصلی را دارد.
- منوی کناری و صفحه پروفایل بازطراحی شده‌اند؛ آیکون تطبیقی و تک‌رنگ Android نیز اضافه شده است.
- رابط بر اساس زبان دستگاه بین فارسی و انگلیسی انتخاب می‌کند و جهت RTL/LTR را تغییر می‌دهد؛ ترجمه کامل resource-based و بازبینی بومی هنوز لازم است.
- انتخاب حالت روشن/تاریک فعال است و ترجیح آن روی دستگاه ذخیره می‌شود.
- گفت‌وگوهای مستقل روی دستگاه ذخیره می‌شوند؛ ایجاد، بازکردن، ادامه، تغییر نام، جست‌وجو و حذف با تأیید کاربر پشتیبانی می‌شود.
- پیام‌ها قابلیت کپی دارند. تاریخچه محلی در SharedPreferences نگهداری می‌شود؛ سقف هر گفت‌وگو ۳۰۰ پیام است و با اضافه‌شدن پیام تازه، قدیمی‌ترین پیام‌ها خودکار حذف می‌شوند. هنگام بارگذاری داده‌های قدیمی نیز ۳۰۰ پیام جدیدتر حفظ می‌شوند. جایگزینی با پایگاه داده محلی تراکنشی پیش از انتشار لازم است.
- مسیر مجوزدهی Gmail با Google Identity Services و دسترسی فقط‌خواندنی در کد وجود دارد؛ اتصال واقعی هنوز روی دستگاه آزمایش و تأیید نشده است.
- گفت‌وگوی عمومی Android و نسخه وب به تابع آنلاین `atlas-chat` در پروژه مستقل ATLAS متصل شده‌اند؛ کلید انتشارپذیر Supabase فقط شناسه عمومی پروژه است و کلیدهای مدل در سمت سرور نگهداری می‌شوند.
- تابع `atlas-chat` از `AI_API_KEY`/`AI_API_URL`/`AI_MODEL`، Groq، Z.AI و Cloudflare Workers AI پشتیبانی می‌کند؛ فقط ارائه‌دهنده‌هایی که Secret و تنظیمات مدلشان ثبت شده باشد فعال می‌شوند.
- گفت‌وگوها در Android روی دستگاه ذخیره می‌شوند؛ نسخه وب فعلاً تاریخچه را فقط در حافظه همان نشست مرورگر نگه می‌دارد.
- ورود حساب، اشتراک و پرداخت، همگام‌سازی ابری، ابزارهای فایل/تصویر/وب/صوت هنوز فعال نیستند.
- ساخت موفق Android به‌تنهایی به معنی تأیید کارکرد Gmail یا آمادگی انتشار نیست.

## معماری و امنیت
- Android: Kotlin + Jetpack Compose
- لایه‌های UI، Domain، Data و Core از هم جدا نگه داشته شده‌اند.
- ترافیک HTTP ناامن در Manifest غیرفعال شده است.
- کلیدهای مدل و سرویس‌ها نباید داخل APK یا GitHub قرار گیرند.
- پروژه مستقل ATLAS Supabase با ref `wwlyvojtsrklcpqsloqz` برای اجرای تابع گفت‌وگو استفاده می‌شود؛ هیچ تغییری در schema دیتابیس، کاربران، Auth یا RLS انجام نشده است.
- تابع عمومی گفت‌وگو فعلاً بدون ورود کاربر فراخوانی می‌شود و محدودیت درخواست داخل حافظه Edge است؛ برای انتشار پرترافیک، سهمیه پایدار و احراز هویت کاربر باید تکمیل شود.
- Gmail فقط‌خواندنی در Android پیاده‌سازی شده اما اتصال OAuth روی دستگاه و تأیید عمومی Google هنوز انجام نشده است.

## ساخت و انتشار
- GitHub Actions برای بررسی کامپایل و بسته‌بندی داخلی استفاده می‌شود.
- هیچ APK یا AAB امضاشده‌ای در این مرحله ساخته یا منتشر نشده است؛ کلید امضای انتشار هنوز از کاربر دریافت نشده است.
- انتشار عمومی فقط پس از تکمیل قابلیت‌ها، تست دستگاهی، بررسی امنیت و حریم خصوصی، آماده‌سازی امضای release و تولید AAB انجام می‌شود.

# ATLAS AI | اطلس AI

اپلیکیشن دستیار هوش مصنوعی چندزبانه با تجربه فارسی‌محور، برای عرضه جهانی در Android و سپس پلتفرم‌های دیگر.

## هویت محصول
- برند: **ATLAS AI**
- نام فارسی: **اطلس AI**
- شعار: **هوشمندی بدون مرز**
- زبان فعلی رابط Android: فارسی؛ ترجمه کامل انگلیسی و دری هنوز تکمیل نشده است.

## قابلیت‌های موجود در این مرحله
- رابط Android با Jetpack Compose و بخش‌های اصلی محصول.
- گفت‌وگوهای محلی که با AES-256-GCM رمزنگاری می‌شوند؛ کلید ۲۵۶ بیتی در Android Keystore نگهداری می‌شود.
- فهرست تاریخچه، بازکردن گفت‌وگوی قبلی، حذف یک گفت‌وگو و پاک‌کردن همه تاریخچه.
- نگهداری محدود به ۴۰ گفت‌وگو و ۳۰۰ پیام برای هر گفت‌وگو؛ با رسیدن به سقف، قدیمی‌ترین پیام‌ها خودکار حذف می‌شوند.
- ثبت اتمیک و رمزنگاری‌شده پیام و فراداده گفت‌وگو؛ مرتب‌سازی پیام‌های باقی‌مانده بر اساس شناسه افزایشی برای حفظ جدیدترین ۳۰۰ پیام.
- مهاجرت تاریخچه قدیمی JSON با بررسی رمزگشایی و تطبیق داده پیش از حذف نسخه متن‌آشکار.
- تغییر واقعی پوسته روشن/تاریک با ذخیره انتخاب کاربر روی دستگاه.
- بخش‌های کاوش دستیارها، ابزارها، حساب و اشتراک فعلاً نمایشی هستند.

## مواردی که هنوز عملیاتی نیستند
- موتور هوش مصنوعی و پاسخ‌دهی آنلاین.
- ورود اصلی با Google و حساب مهمان آنلاین.
- سهمیه مصرف سرور-محور و پرداخت.
- همگام‌سازی ابری، ابزارهای فایل/تصویر/وب و قابلیت‌های صوتی.
- خروجی داده و ترجمه کامل چندزبانه.
- آزمون کامل کامپایل، دستگاه واقعی و آزمون امنیتی انتشار.

## معماری و امنیت
- Android: Kotlin + Jetpack Compose.
- تاریخچه به‌صورت محتوای JSON رمزنگاری‌شده در فایل محلی حافظه خصوصی Android ذخیره می‌شود و به ابر ارسال نمی‌شود. پیاده‌سازی Android Keystore و مهاجرت فایل هنوز باید روی دستگاه واقعی آزمایش شود.
- کلیدهای ارائه‌دهندگان هوش مصنوعی نباید داخل برنامه یا مخزن قرار بگیرند.
- هیچ اتصال یا تغییری در Supabase و هیچ حساب کاربری آنلاین در این مرحله انجام نشده است.
- API عمومی بدون احراز هویت و سهمیه پایدار برای انتشار عمومی قابل قبول نیست.

## سیاست ساخت
ساخت APK/AAB و انتشار فقط پس از درخواست مشخص و اجرای اعتبارسنجی مجاز است. هیچ فایل ناقص به‌عنوان نسخه آماده انتشار معرفی نمی‌شود.

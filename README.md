# هوش مصنوعی

اپلیکیشن دستیار هوشمند اندروید با رابط فارسی، ساخته‌شده با Kotlin و Jetpack Compose.

## محدوده مرحله اول

- صفحه آغازین فارسی و راست‌به‌چپ
- محیط گفت‌وگو با حباب پیام‌ها
- کادر نوشتن و ارسال پیام
- پیشنهادهای شروع سریع
- پنجره تنظیمات اولیه
- نگهداری موقت پیام‌ها فقط در حافظه برنامه

## وضعیت اتصال و داده‌ها

این مرحله عمداً بدون دیتابیس و بدون اتصال شبکه ساخته شده است. پیام‌ها پس از بسته‌شدن برنامه ذخیره نمی‌شوند. پاسخ نمایشی برنامه فقط اعلام می‌کند که اتصال واقعی هنوز فعال نشده است؛ هیچ پاسخ ساختگی از مدل ارائه نمی‌شود.

هیچ پروژه Supabase در این مرحله تغییر نکرده و تابع Edge Function نیز Deploy نشده است.

## معماری آماده‌شده برای مراحل بعد

- Android: Kotlin + Jetpack Compose
- Backend بعدی: Supabase Edge Function مستقل
- کلید ارائه‌دهنده هوش مصنوعی: فقط در Edge Function Secrets
- احراز هویت، تاریخچه ابری، سهمیه مصرف و اتصال واقعی: مراحل بعدی

## متغیرهای سرور در مرحله اتصال

- `AI_API_KEY`: کلید خصوصی ارائه‌دهنده
- `AI_API_URL`: آدرس پایه API سازگار با OpenAI
- `AI_MODEL`: شناسه مدل انتخاب‌شده

کلید واقعی نباید در GitHub، کد اندروید، APK یا گفت‌وگو قرار بگیرد. آن را بعداً مستقیماً در Secrets پروژه مستقل وارد می‌کنیم.

## پیش‌نیازهای توسعه

- Android Studio
- JDK 17
- Android SDK 35

## گام‌های بعدی

1. تکمیل و آزمایش ساخت اندروید
2. تعیین ارائه‌دهنده و مدل هوش مصنوعی
3. آماده‌سازی Supabase مستقل برای این برنامه
4. پیاده‌سازی احراز هویت و محدودیت مصرف
5. اتصال امن اپلیکیشن به Edge Function
6. تست روی گوشی و ساخت APK امضاشده

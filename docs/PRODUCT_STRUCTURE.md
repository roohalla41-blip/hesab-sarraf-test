# نقشه ساختار محصول ATLAS AI

## صفحات اصلی
1. گفت‌وگو: شروع مکالمه و نمایش پیام‌ها؛ موتور هوش مصنوعی عمومی هنوز متصل نیست.
2. تاریخچه: فهرست چند گفت‌وگوی مستقل، بازکردن، ادامه و حذف با تأیید؛ جست‌وجو و تغییر نام هنوز در دست توسعه.
3. کاوش دستیارها: حالت‌های نویسندگی، یادگیری، برنامه‌نویسی، پژوهش و کسب‌وکار؛ فعلاً ساختار رابط.
4. ابزارها: فایل، تصویر، وب، صوت و کدنویسی؛ تا زمان اتصال سرویس‌ها غیرفعال.
5. اتصال برنامه‌ها: مسیر Gmail فقط‌خواندنی در کد پیاده‌سازی شده؛ تست دستگاهی و تأیید OAuth باقی است.
6. حساب کاربری: نمایه مهمان؛ ثبت‌نام و ورود آنلاین فعال نیست.
7. طرح‌های اشتراک: طرح‌های نمایشی؛ قیمت، پرداخت و سهمیه واقعی تعریف نشده‌اند.
8. تنظیمات: تغییر روشن/تاریک با ذخیره محلی؛ زبان فعلی فارسی و چندزبانگی کامل در دست توسعه.
9. حریم خصوصی و امنیت: اطلاع‌رسانی درباره ذخیره محلی و اصول اتصال امن.
10. راهنما و پشتیبانی: راهنمای وضعیت قابلیت‌ها و مسیرهای آینده.

## وضعیت پیاده‌سازی
- رابط Android با Jetpack Compose پیاده‌سازی شده است.
- منوی کناری گروه‌بندی و بازطراحی شده و صفحه پروفایل مهمان توضیح روشن‌تری درباره داده‌های محلی دارد.
- حالت روشن/تاریک قابل تغییر است و انتخاب کاربر در SharedPreferences ذخیره می‌شود.
- تاریخچه چندگفت‌وگویی روی دستگاه نگهداری می‌شود؛ عنوان مکالمه از نخستین پیام کاربر ساخته می‌شود و گفت‌وگوها را می‌توان باز کرد، ادامه داد یا با تأیید حذف کرد.
- ساختار قبلی ذخیره یک گفت‌وگو هنگام ارتقا به ساختار جدید مهاجرت می‌کند.
- گفت‌وگوی عمومی تا اتصال موتور AI فقط وضعیت عدم اتصال را به‌صورت روشن نمایش می‌دهد.
- مسیر OAuth و Gmail API با scope فقط‌خواندنی در سورس وجود دارد؛ هنوز روی گوشی واقعی نصب، مجوزدهی و آزمایش موفق آن تأیید نشده است.
- حساب کاربری، پایگاه داده ابری، پرداخت و ابزارهای پیشرفته هنوز فعال نیستند.
- build خودکار برای بررسی کامپایل و بسته‌بندی داخلی است؛ خروجی آزمایشی به‌صورت artifact منتشر نمی‌شود.

## معماری
- UI: Jetpack Compose در Android و HTML/CSS/JavaScript در پیش‌نمایش وب
- Domain: مدل‌ها و قراردادهای مستقل از ارائه‌دهنده
- Data: ذخیره محلی چندگفت‌وگو
- Remote: مرز API سمت سرور؛ اتصال عملیاتی هنوز انجام نشده
- Security: کلیدهای محرمانه فقط در Secret Manager سمت سرور؛ بدون قراردادن secret در برنامه

## اصول امنیت و حریم خصوصی
- هیچ کلید محرمانه‌ای داخل برنامه Android، APK یا GitHub قرار نمی‌گیرد.
- پروژه Supabase یا پایگاه داده خارجی در این مرحله متصل یا تغییر داده نشده است.
- اطلاعات پیش‌نمایش به‌عنوان داده واقعی کاربر تلقی نمی‌شود.
- قابلیت‌های غیرفعال باید با وضعیت روشن نمایش داده شوند.

# ATLAS AI Android preview APK

This branch packages the current hosted ATLAS AI web preview in an Android WebView shell.

- Display name: اطلس AI
- Brand: ATLAS AI
- Tagline: هوشمندی بدون مرز
- Web preview: https://roohalla41-blip.github.io/hesab-sarraf-test/
- Application ID: com.hooshmasnooi.app
- Minimum Android: API 26
- Build output: app/build/outputs/apk/debug/app-debug.apk
- Workflow artifact: atlas-ai-debug-apk

This is an installable preview/debug APK, not a Play Store release. The app requires an internet connection and loads the hosted web preview. No provider secret is packaged in the Android app.
